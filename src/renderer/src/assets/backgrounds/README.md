# Haikei backgrounds

1. Open https://haikei.app and pick a generator (Layered Waves or Stacked Waves match the mockup).
2. Size 1600 x 1000. Use colours from the palette: #171310 and #6F4E37 for the base, #E6E0F0 sparingly.
3. Export as SVG and save it here as `haikei-bg.svg`.

Any `.svg` in this folder is picked up at build time (a file with "haikei" in its name wins).
With no file here, the built-in `../bg.svg` is used. Haikei is only needed to make the file, not at runtime.
